# Knowledge Compilation Prompt

你要把一套完整的长课程或培训 Evidence 编译为候选 Markdown 知识资产。

开始前必须完整阅读并遵守：

1. `docs/Knowledge_Compilation.md`
2. `docs/Human_Review.md`
3. `templates/Course_Knowledge.md`
4. 本课程全部 TXT、SRT 和 `manifest.json`

任务要求：

- 先盘点全部输入，核对 TXT/SRT 配对、时长、顺序和缺失项。
- 为每个来源分配稳定编号，记录文件名、时长、主要主题和相邻边界判断。
- 先理解完整课程，再建立语义章节；不得逐文件总结后机械拼接。
- 只把 Evidence 支持的内容写成课程知识。
- 不得用模型已有知识静默修正或补写课程观点。
- 区分明确课程内容、讲师观点、示例、学员推测、模型推断和无法确认内容。
- 对无法确认的术语、数字、单位、品牌、标准号、型号、上下文和推断使用 `[待确认]`。
- 核心结论、案例、争议和待确认项尽量使用 `[来源编号 HH:MM:SS]` 回指 Evidence。
- 去除机械重复和无效口语，但保留新增条件、限制、例外、案例和能力边界。
- 按模板生成一个候选 `Course_Knowledge.md`，状态必须是“候选，待人工审阅”。
- 完成后报告输入盘点、边界判断、待确认项和无法覆盖的内容，然后停止等待人工审阅。

禁止：

- 联网补写（除非用户明确要求，并与课程内容分层）；
- 把流畅性置于证据之上；
- 把模型推断伪装成课程事实；
- 删除仍未解决的不确定性；
- 宣称候选输出已经获得人工批准。
