# Human Review Protocol

> AI output ≠ approved knowledge.

模型输出默认是候选知识。只有人工审阅通过后，才能将其作为最终 `Course_Knowledge.md` 长期复用。

## Review Checklist

- [ ] 课程范围、目标和章节结构与完整 Evidence 一致
- [ ] 数字
- [ ] 百分比
- [ ] 单位
- [ ] 日期与时间
- [ ] 人名
- [ ] 公司与品牌
- [ ] 标准号
- [ ] 产品型号
- [ ] 专业术语
- [ ] 关键因果关系
- [ ] 条件、限制、例外和失效场景
- [ ] AI 是否补写了原文不存在的内容
- [ ] 讲师观点、学员推测和模型推断是否被正确区分
- [ ] `[待确认]` 是否逐项处理或保留
- [ ] 来源编号存在且时间定位成立
- [ ] 跨章节合并是否改变原始语义
- [ ] 重复删除是否误删新增信息
- [ ] Markdown 是否完整、可独立阅读

## Approval Record

最终文档应记录审阅状态、审阅人或角色、审阅日期和仍保留的限制。没有审批记录时，状态保持“候选”。
